# D-Fire 라벨 지침 v1.0

## 클래스

- `0 smoke`: 실제 연기 덩어리를 둘러싸는 박스
- `1 fire`: 실제로 보이는 불꽃 영역을 둘러싸는 박스
- 불이나 연기가 없는 이미지는 빈 라벨 파일을 유지한다.

## 포함하지 않는 대상

- 구름, 안개, 수증기, 먼지
- 노을, 태양, 가로등, 전조등, 반사광
- 판단하기 어려울 정도로 흐리거나 가려진 장면

## 품질 검사

- 각 라벨 행은 `class x_center y_center width height` 다섯 값이어야 한다.
- 클래스 번호는 0 또는 1만 허용한다.
- 좌표와 크기는 0부터 1 사이이며 width와 height는 0보다 커야 한다.
- 이미지와 라벨 파일의 stem이 반드시 일치해야 한다.
- 공식 D-Fire fold 1을 사용하고 train, validation, test 간 중복을 허용하지 않는다.

## 현재 한계

D-Fire 공식 분할은 이미지 파일 목록을 제공하지만 사건, 카메라, 장소 단위의 그룹 정보는 제공하지 않는다. 따라서 공식 분할을 기준선으로 사용하되, 실제 CCTV형 영상을 추가할 때는 동일 영상에서 나온 프레임이 여러 split에 섞이지 않도록 `source_group`을 별도로 기록해야 한다.
