# 5주차 진행 보고

기간은 2026년 9월 28일부터 10월 2일까지다. 실제 투입시간과 활동 사진은 제출 전에 직접 입력해야 한다.

## 이번 주 목표

D-Fire 데이터 v1의 재현 가능한 분할과 검증 절차를 확정하고 YOLO26n 본 학습을 준비한다.

## 현재까지 확인된 결과

- D-Fire 이미지와 라벨 21,527쌍을 확인했다.
- 빈 라벨 9,838개는 정상 배경 이미지로 확인했다.
- 클래스 박스는 smoke 11,865개, fire 14,692개다.
- YOLO26n 3epoch 시험 학습이 완료됐다.
- 3epoch 결과는 Precision 0.6683, Recall 0.6068, mAP50 0.6621, mAP50-95 0.3614다.
- best.pt와 학습 결과 파일이 Google Drive에 저장됐다.

## 이번 주 자동화

- 공식 fold 1을 적용하는 데이터 준비 스크립트
- 이미지와 라벨 짝, 클래스, 좌표를 검사하는 QA
- dataset manifest, split CSV, data YAML 자동 생성
- Colab 재현 노트북

## 미완료

- 80epoch 본 학습
- validation 클래스별 결과 정리
- 상위 FP와 FN 각 20개 선정 및 원인 분류
- 모델카드 작성과 최종 best.pt 확정

## 사용자 입력이 필요한 증빙

- 실제 투입시간
- 작업 화면 또는 팀 활동 사진
- 팀원 역할 분담
- 지도교수 또는 멘토 피드백과 반영 내용

## 다음 결정

본 학습에서는 모델, 데이터, seed를 고정하고 메모리 상황에 따라 batch만 조정한다. validation 결과로 모델과 confidence를 선택하고 test는 모델 선택이 끝날 때까지 사용하지 않는다.
